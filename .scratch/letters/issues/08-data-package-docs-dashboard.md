## Comments

### 票 02 交接

- 票 02 新加了一张 `letter_users`（每位用户上次排到哪一天），已经登记进 `USER_DATA`，删号时会删掉。它不是用户内容，数据包不用导出；导入时也不用管。导入的对话会让相识纪念从更早的那天算起，这是规格要的。

### 票 04 交接

- 配置指南「信」里写传配乐时，以这些为准：
  - 命令是 `eidolon letter-music upload <目录>`，Docker 部署里目录要挂进后端容器。
  - 传哪些文件、高潮在哪，由 `characters/letter_music.toml` 定。换了曲子要改这份清单里的文件名和秒数。
  - 文件传到立绘的存储桶（`EIDOLON_STAND_S3_*`）的 `letters/music/` 下，要配好 `EIDOLON_STAND_ASSETS_URL`，存储桶要对浏览器回 CORS 头（和酒吧音频一样）。
  - 不传就没有配乐，信照样能看。
