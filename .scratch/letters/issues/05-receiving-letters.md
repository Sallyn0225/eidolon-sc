# 05: 收信：弹出、她的信、删除

**What to build:** 有没读过的信时，制作人打开网站（或从她的对话页切到别处）整屏弹出最早那封的信封；跳过的不再弹，换设备也一样。她的对话页页首能看到她写的所有信，对话列表上她那一行用小信封标出没读过的信。所有的信的列表里没读过的在最上面，其余按月分组。两个列表里都能删掉一封信。

见 spec「前端」「接口」，界面原型 `prototype/letters-ui` 的方案 C 加方案 A 的全局入口。

**Blocked by:** 01

**Status:** done

- [x] 接口：标弹过、删除（连语音一起删），别人的信 404；最新对话列表每一行多「有没有没读过的信」，现有 60 秒轮询顺带带回来。
- [x] 弹出：有没读过也没弹过的信时弹最早一封；进入外壳时或从她的对话页切到别的页面时；在她的对话页上、通话中不弹；每次打开网站最多一封；信封出现时标弹过。选哪封、什么时候弹是纯函数，有单测。
- [x] 她的对话页页首、电话键旁一个信封键（她有信时才出现），点开只列她的信、从新到旧（电脑对话框、手机底部抽屉）；从这里拆的信收起时飞回这个键。
- [x] 对话列表上她那一行有没读过的信时，名字后面一枚小信封；读屏有一句说明。
- [x] 全局列表改成：没读过的在最上面，其余按月分组、从新到旧（纯函数，有单测）。自动弹出的信收起时飞回页首信封键。
- [x] 删除：两个列表里电脑右键、手机长按出「删除这封信」，确认框确认后删（照删历史对话的确认框）。
- [x] 场合的叫法简短，不加说明小字。
- [x] `DESIGN.md` 加一节「信」：信纸信封的固定浅色、她的颜色用在哪、信上的字号、拆开和收起的动效、列表行上的小信封、页首信封键的点；信纸信封的固定色进对比度测试。
- [x] 本地构建版上用 Playwright 看弹出的时机（对话页上不弹、切走后弹、跳过后不再弹）、两个列表、删除，电脑和手机各截图。

## Comments

### 票 01 交接

- `popped_at` 列已有、从没写过；列表接口已经带 `popped`。拆信层由 `LetterProvider` 持有，`open(letter, target)` 的 `target` 就是收起时飞回的键，她的对话页的键传自己的 ref 即可。
- 页首信封键的点只在载入和切回标签页时拉列表更新；停在页面上不会自己出现新信，弹出和对话列表行的轮询做好后看要不要让它跟着刷新。
- DESIGN.md 还没动：「Conversation list · 页首」那一节仍只写服务状态和公告铃铛，信纸信封的固定色、Klee One、拆开和收起的动效都没写，按 spec 在这一票加「信」一节。对比度测试已经加了信纸、信封的那三对。
- 列表现在只是从新到旧一列，没有按月分组和「没读过的在最上面」；列表行是 `LetterButton.tsx` 里的 `LetterRow`。

### 票 03 交接

- 删除一封信要连 `letter_voices` 里它的几块一起删（`letter_id` 有外键）。读一封的 `voice` 用 `/api/letters/{id}/voice/{block}`，缓存一年 immutable；`letters.id` 是 AUTOINCREMENT，删了不会复用，旧缓存不会配到新信上。
- `DESIGN.md` 的「Icons」一节还没登记信的图标：`LetterIcon`（页首信封键）、`LetterSoundIcon` / `LetterMutedIcon`（读信时右上角的静音键），写「信」一节时一起加上。
- 自动弹出的信封一出现，拆信层就开始取这封信的语音（几百 KB 的 mp3）；被跳过的信也取过了，弹出时机做好后看要不要改成拆开才取。

### 实现说明（票 05）

- **后端**：`Letters.mark_popped`、`delete`（连 `letter_voices` 一起删）、`unread_from`；接口 `PUT /api/letters/{id}/popped`、`DELETE /api/letters/{id}`，别人的、没有的一律 404。`/api/conversations/latest` 每一行多 `unread_letter`。测试在 `test_receiving_letters.py`。
- **前端纯函数**（`lib/letter.ts`）：`letterToPop`（选哪封、在对话页上和通话中不弹）、`groupLetters` / `letterMonth`（没读过的一组，其余按写信那天的月份）、`hersOf`、`unreadFrom`、`lettersBehind`；`arrange` 多一个选项 `unreadLetters`，行上多 `hasUnreadLetter`；`navShell.isConversationPage`。
- **`LetterProvider`** 管弹出的时机：进入外壳、离开对话页（离开时先重拉一遍信）各是一个时机；在对话页上、通话中时机留着，等离开、挂断、角色载入了再看。「这次打开网站弹过了」记在模块变量里，去一趟外壳外面再回来也不再弹。信封出现（取到信）时标弹过。提供 `home`（页首信封键的 ref）和 `remove`。
- **列表**：`LetterList.tsx` 是两个列表共用的（右键 / 长按删除、确认框嵌在列表所在的浮层里，删完浮层还开着）；`LetterButton.tsx` 里是页首信封键、`HerLetterButton`（她的对话页，电话键左边）和 `UnreadLetterMark`（对话列表行上的小信封）。
- **判断**：
  - 「在她的对话页上不弹」照用户故事 29 的本意读成任何一位的对话页（在恋鐘的对话页上也不弹真乃的信），规格措辞已经跟着改。
  - 小信封和页首的点都从信的列表算，不直接用 `unread_letter`：本地拆开、删掉马上就变。`unread_letter` 只用来发现信的列表落后了（`lettersBehind`），落后就重拉。代价是她已经有一封没读过的信时又写了一封，轮询看不出来，要等切回标签页或离开对话页才拉到。
  - 票 03 提的「自动弹出的信封一出现就取语音，跳过的也取过」没改：每次打开网站最多弹一封、跳过的不再弹，多取的最多是一封的语音；改成拆开才取，拆开以后要多等语音。
  - 她的信封键在看历史对话时照样在（规格只说她有信时才出现）。
- **验收**：本地构建版上用 Playwright 走了一遍电脑和手机（弹出时机、跳过后不再弹、每次最多一封、两个列表、右键和长按删除），16 项都过；截图看过，没留存。
- **审查**：两处判断题没改，留着：她的信封键的面板和成就面板都是「宽屏 Dialog、窄屏 Drawer」，可以抽成项目组件；页首键右上角的点在几处各写了一遍。
