# 24: 文档和条款

**What to build:** 部署者读部署文档就知道怎么配生图、需要什么样的中转、要担什么条款风险。用户读隐私政策就知道照片存在哪、发给了谁、管理者看不到，读使用条款就知道自带的 key 要自己遵守那项服务的条款。规格见 `../spec.md`「文档和条款」一节，以及 `10-who-pays-under-tos.md`、`07-storage-and-lifecycle.md` 的 Answer。

**Blocked by:** 19, 20, 21

**Status:** ready-for-human

- [x] **`docs/configuration.md` 加生图一节**，英文、日文版同步：
  - 两种接口形式怎么填，环境变量（`NOVELAI_*`、`EIDOLON_PHOTOS_PER_HOUR`、代理的 `image`、`own_image`）。
  - 画风怎么写：仓库默认空，不推荐具体画师。
  - 需要什么样的中转：原样返回 832×1216，只支持这两种接口形式，OpenAI chat 兼容和各家自定义的不支持。
  - 条款风险：NovelAI 禁止把一个订阅给公众共用，拿官方 token 对外开放由部署者自己负责；中转随时可能被封、断掉。
  - 没有判断模型的部署没有照片。
- [x] **隐私政策改三处**，更新日期跟着改：
  - 「我们保存哪些数据」→「对话」：她发给你的照片也存在对话里，只有你能看，随那段对话一起删除，也会进备份。
  - 「这些数据会交给哪些第三方处理」：新加「生图服务」。发出去的是描述照片的英文 tag，不发你说的原话；发给部署者配置的生图服务，填了自带密钥就发给你自己选的服务。
  - 「管理者能看到什么」→「看不到」：加上她发给你的照片。
- [x] **使用条款加一条通用的「自带密钥」**：你自带的 key 由你自己遵守那项服务的条款（例如年龄、用途），LLM、语音合成、语音识别、生图都适用。更新日期跟着改。界面上不加 18 岁提示。

**票 19 留下的（2026-10-17）。** `.env.example` 的生图一段已经写了 `NOVELAI_API_FORMAT`、`NOVELAI_CONCURRENCY`（1 到 10，默认 1）、`NOVELAI_STYLE`，`EIDOLON_PROXY_SERVICES` 的说明加了 `image`，`docs/configuration.md` 照它写、和代码对齐。要写进文档的口径：

- 切换接口形式不会改地址：官方格式填到域名根，OpenAI 图像格式填到 `/v1`。

**票 20 留下的（2026-10-18）。**
- `docs/configuration.md`（和英文、日文版）「网络代理」的表还没有 `own_image` 一行：用户自带的生图，只有 HTTPS 的 NovelAI 官方地址 `image.novelai.net` 走代理，中转一律直连。`.env.example` 已经写了。
- 自带生图的口径：设置页填接口形式、地址、key、模型四项，保存前真生成一张（花用户的额度，不计用量、不进运行记录）；没有判断模型的部署直接拒绝「这个部署发不了照片」。用它生成的照片不计入每小时的照片数，部署者的画风照样生效，一次一张。自带的生图失败（超时以外，包括返回的图尺寸不对）记成「你的生图密钥没能用」，不改用部署者的。公开部署里自带的地址只能是 HTTPS 的公网地址，下载 `url` 也一样。
- 设置页 ⓘ 里那句「自带的密钥调用失败时，这一轮会失败并提示是哪一项出了问题」对生图不准（回合照常，只是照片没发出来），写条款和隐私说明时一起看要不要改（那段措辞跟隐私说明逐句对齐过）。
